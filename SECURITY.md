# Security Policy

## Supported versions

Security fixes are evaluated for the latest development branch and the latest published release, if one exists. Older builds may not receive fixes.

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, private tokens, personal data, or sensitive console information in a public issue.

Use GitHub's **Report a vulnerability** feature on this repository when it is available. If private vulnerability reporting is not enabled, contact the repository maintainer through a verified GitHub profile channel and share only the minimum details needed for a safe investigation.

Include:
- Affected release or commit.
- Impact and conditions required to reproduce.
- A minimal proof of concept that does not expose real accounts or data.
- Any suggested mitigation.

Please allow reasonable time for investigation and a fix before public disclosure. Do not test against systems, accounts, or services you do not own or have permission to assess.
