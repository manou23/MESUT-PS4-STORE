# Contributing

Thank you for helping improve MESUT PS4 STORE.

## Guidelines
- Keep the app controller-first and readable from a TV viewing distance.
- Preserve Arabic RTL and English LTR layouts.
- Keep the catalogue schema backwards-compatible where possible.
- Never add commercial game package links without clear redistribution authorization.
- Do not add credentials, tokens, private URLs, or personal data.
- Include reproducible build and test notes with code changes.

## Catalogue contributions
Every package entry must include a canonical source and rights statement. Package URLs are accepted only when the publisher permits distribution or the user explicitly supplies a URL for their own authorized content.

## Versioning
- Patch releases: fixes and documentation corrections.
- Minor releases: backward-compatible features.
- Major releases: architecture or catalogue breaking changes.

Do not mark a release as ready until its build and package have been tested.
